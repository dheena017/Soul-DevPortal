# Bug Bounty Learning

A structured workspace for learning web & API security, practicing with labs, organizing tools, and documenting bug bounty reports.

## Structure

- `01-Notes/` — Core concepts, protocols, and security notes
- `02-Practice/` — Hands-on HTTP requests and web security labs
- `03-Tools/` — Security tools, scripts, and wordlists
- `04-Reports/` — Vulnerability write-ups and report templates
